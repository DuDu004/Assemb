# Finding Multiples of K - K의 배수 찾기

*MASM + Irvine32 예제 정리*

## 1. 문제 번역

크기가 $N$인 바이트 배열에서 $N$보다 작은 $K$의 모든 배수를 찾는 프로시저를 작성한다.

- 프로그램 시작 시 배열의 모든 원소를 0으로 초기화한다.
- 배수를 발견하면 해당 배열 원소를 1로 설정한다.
- 프로시저는 자신이 수정하는 모든 레지스터를 저장하고 복원해야 한다.
- 프로시저를 두 번 호출한다. 첫 번째는 $K=2$, 두 번째는 $K=3$이다.
- $N=50$으로 설정한다.
- 디버거에서 배열 원소가 올바르게 설정되었는지 확인한다.

## 2. MASM 코드

```asm
INCLUDE Irvine32.inc

.data
    N = 50
    numbers BYTE N DUP(0)

.code
main PROC
    ; K = 2의 배수를 표시
    mov esi, OFFSET numbers
    mov eax, 2
    mov ecx, N
    call FindMultiples

    ; K = 3의 배수를 표시
    mov esi, OFFSET numbers
    mov eax, 3
    mov ecx, N
    call FindMultiples

    exit
main ENDP

;--------------------------------------------------
; FindMultiples
; N보다 작은 K의 배수에 해당하는 배열 원소를 1로 설정
;
; 입력:
;   ESI = 배열 시작 주소
;   EAX = K
;   ECX = N
;--------------------------------------------------
FindMultiples PROC USES eax ebx ecx edx esi edi
    mov ebx, eax        ; EBX = K
    mov edi, 0          ; EDI = 현재 인덱스

L1:
    mov eax, edi
    xor edx, edx
    div ebx             ; EDX = 인덱스 % K

    cmp edx, 0
    jne NotMultiple

    mov BYTE PTR [esi + edi], 1

NotMultiple:
    inc edi
    loop L1

    ret
FindMultiples ENDP

END main
```

## 3. 코드 설명

### 배열 초기화

```asm
N = 50
numbers BYTE N DUP(0)
```

`numbers`는 50개의 바이트 원소로 이루어지며, 모든 원소가 처음에 0으로 초기화된다.

### 프로시저 호출

| 레지스터 | 의미 |
|---|---|
| ESI | 배열의 시작 주소 |
| EAX | 배수의 기준 $K$ |
| ECX | 검사할 원소 개수 $N$ |

첫 번째 호출은 $K=2$, 두 번째 호출은 $K=3$이다.

### 배수 판별

```asm
mov eax, edi
xor edx, edx
div ebx
```

`DIV`는 EDX:EAX를 EBX로 나누고, 나머지를 EDX에 저장한다.

```asm
cmp edx, 0
jne NotMultiple
mov BYTE PTR [esi + edi], 1
```

나머지가 0이면 해당 인덱스는 $K$의 배수이므로 원소를 1로 바꾼다. 0이 아니면 건너뛴다.

### 레지스터 저장 및 복원

`FindMultiples PROC USES eax ebx ecx edx esi edi`에서 `USES`는 프로시저가 수정하는 레지스터를 스택에 저장하고, 반환할 때 복원한다. 따라서 호출한 쪽의 레지스터 값이 유지된다.

## 4. 실행 과정

배열 인덱스는 0부터 49까지다.

- 첫 번째 호출($K=2$): 0, 2, 4, ..., 48번 인덱스가 1이 된다.
- 두 번째 호출($K=3$): 0, 3, 6, ..., 48번 인덱스가 1이 된다. 이미 1이던 원소는 그대로 유지된다.

| 인덱스 | 2의 배수 | 3의 배수 | 최종 값 |
|:---:|:---:|:---:|:---:|
| 0 | 예 | 예 | 1 |
| 1 | 아니요 | 아니요 | 0 |
| 2 | 예 | 아니요 | 1 |
| 3 | 아니요 | 예 | 1 |
| 4 | 예 | 아니요 | 1 |
| 5 | 아니요 | 아니요 | 0 |
| 6 | 예 | 예 | 1 |
| 7 | 아니요 | 아니요 | 0 |
| 9 | 아니요 | 예 | 1 |
| 10 | 예 | 아니요 | 1 |

## 5. 예상 결과 (디버거 확인)

- 호출 전: 인덱스 0~49의 모든 값이 0이다.
- 두 번 호출 후: 2 또는 3의 배수인 인덱스의 값이 1이다.
- 0~49 중 2의 배수는 25개, 3의 배수는 17개, 6의 배수(둘 다)는 9개이므로, 1로 설정되는 원소는 $25+17-9=33$개이다.

## 6. 주의 사항

- **K = 0이면 안 된다.** `DIV`에서 0으로 나누기 예외가 발생한다. 호출 전에 K가 1 이상인지 확인해야 한다.
- 인덱스 0은 $0 \bmod K = 0$이므로 배수로 판정되어 1이 된다. 0을 배수에서 제외하려면 별도 조건을 추가해야 한다.
- `N = 50`은 `=`로 정의한 상수(EQU와 같은 기능)이다.
