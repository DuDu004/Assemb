# Fibonacci Generator - 피보나치 수열 생성기

*MASM + Irvine32, DWORD 배열에 피보나치 수열 N개 저장*

## 1. 문제 번역

배열에 피보나치 수열의 $N$개 값을 생성하여 저장하는 프로시저를 작성하시오. 배열의 각 원소는 32비트 doubleword여야 한다.

- 입력 매개변수: doubleword 배열의 주소(ESI), 생성할 값의 개수(ECX)
- 테스트 프로그램에서 $N = 47$을 전달하여 호출한다.
- 배열의 첫 번째 값은 1, 마지막 값은 2,971,215,073이어야 한다.
- Visual Studio 디버거로 배열 내용을 확인한다.

## 2. MASM 코드

```asm
INCLUDE Irvine32.inc

.data
    fibArray DWORD 47 DUP(?)

.code
main PROC
    mov esi, OFFSET fibArray
    mov ecx, 47
    call Fibonacci

    ; 마지막 원소(인덱스 46) 확인
    mov eax, [esi + 46 * TYPE fibArray]
    call WriteDec
    call Crlf

    exit
main ENDP

;--------------------------------------------------
; Fibonacci
; 배열에 피보나치 수열의 N개 값을 저장한다.
; 입력:
;   ESI = 배열의 주소
;   ECX = 생성할 값의 개수
;--------------------------------------------------
Fibonacci PROC USES eax ebx edx esi ecx
    cmp ecx, 0
    je FibDone

    mov eax, 1
    mov ebx, 1

FibLoop:
    mov [esi], eax
    add esi, TYPE DWORD

    ; 다음 피보나치 값 계산
    mov edx, eax
    mov eax, ebx
    add ebx, edx

    loop FibLoop

FibDone:
    ret
Fibonacci ENDP

END main
```

## 3. 코드 설명

| 코드 | 설명 |
|---|---|
| `fibArray DWORD 47 DUP(?)` | 원소 하나가 4바이트인 배열 47개를 만든다. |
| `mov esi, OFFSET fibArray` | 배열의 시작 주소를 ESI에 저장한다. |
| `mov ecx, 47` | 생성할 원소 개수를 ECX에 저장한다. |
| `mov eax, 1` / `mov ebx, 1` | 첫 두 피보나치 값을 준비한다. |
| `mov [esi], eax` | 현재 값을 배열에 저장한다. |
| `add esi, TYPE DWORD` | 다음 원소 주소로 이동한다(4바이트). |
| `mov edx, eax` / `mov eax, ebx` / `add ebx, edx` | 다음 피보나치 값을 계산한다. |
| `loop FibLoop` | ECX를 1 감소시키고 0이 아니면 반복한다. |
| `USES ... esi ecx` | 프로시저 종료 시 ESI, ECX 등을 복원한다. |

수열은 1, 1, 2, 3, 5, 8, ... 순서로 만들어진다.

## 4. 배열 내용과 인덱스

피보나치 수열을 $F_1 = F_2 = 1$로 두면, 인덱스 $k$의 원소는 $F_{k+1}$이다.

| 인덱스 | 값 |
|---|---|
| 0 | 1 |
| 1 | 1 |
| 2 | 2 |
| 3 | 3 |
| 4 | 5 |
| 5 | 8 |
| ... | ... |
| 44 | 1,134,903,170 |
| 45 | 1,836,311,903 |
| 46 | 2,971,215,073 |

- 마지막 원소(인덱스 46, 47번째 값)는 2,971,215,073이다. 문제의 요구 조건과 일치한다.
- 이 값은 $2^{32} - 1 = 4{,}294{,}967{,}295$ 이하이므로 DWORD에 정상적으로 저장된다.
- $N = 47$이 맞는 값이며, 코드를 수정할 필요가 없다.
