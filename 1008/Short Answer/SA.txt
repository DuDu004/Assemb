1. Which instruction pushes all of the 32-bit general-purpose registers on the stack?
  한글 번역: 모든 32비트 범용 레지스터를 스택에 저장하는 명령어는 무엇인가?
    정답: PUSHAD
    해설: PUSHAD는 EAX, ECX, EDX, EBX, 원래 ESP 값, EBP, ESI, EDI를 스택에 저장한다.

2. Which instruction pushes the 32-bit EFLAGS register on the stack?
  한글 번역: 32비트 EFLAGS 레지스터를 스택에 저장하는 명령어는 무엇인가?
    정답: PUSHFD
    해설: PUSHFD는 32비트 EFLAGS 레지스터의 값을 스택에 저장한다. EFLAGS에는 CF, ZF, SF, OF 등의 상태 플래그가 포함된다.

3. Which instruction pops the stack into the EFLAGS register?
  한글 번역: 스택의 값을 꺼내 EFLAGS 레지스터에 저장하는 명령어는 무엇인가?
    정답: POPFD
    해설: POPFD는 스택 최상단의 32비트 값을 EFLAGS 레지스터로 가져온다. 실행 후 ESP는 4바이트 증가한다.

4. Challenge: Another assembler (called NASM) permits the PUSH instruction to list multiple specific registers. Why might this approach be better than the PUSHAD instruction in MASM? 
Here is a NASM example: 
 PUSH EAX EBX ECX

  한글 번역: NASM이라는 어셈블러는 PUSH 명령어에 여러 레지스터를 지정할 수 있다. 이 방식이 MASM의 PUSHAD 명령어보다 나은 이유는 무엇인가?
    정답: PUSHAD는 8개의 범용 레지스터를 모두 저장하지만, 여러 레지스터를 선택하는 방식은 필요한 레지스터만 저장할 수 있다. 따라서 스택 공간을 절약하고 불필요한 작업을 줄일 수 있다.

  한글 번역: PUSH 명령어가 없다고 가정할 때, PUSH EAX와 동일한 기능을 수행하는 두 개의 다른 명령어를 작성하시오.

6. (True/False): The RET instruction pops the top of the stack into the instruction pointer.
  한글 번역: (참/거짓) RET 명령어는 스택 최상단의 값을 꺼내 명령어 포인터에 저장한다.
    정답: True
    해설: RET는 스택에서 반환 주소를 꺼내 명령어 포인터(EIP 또는 RIP)에 저장하여 호출한 위치로 돌아간다.

7. (True/False): Nested procedure calls are not permitted by the Microsoft assembler unless the NESTED operator is used in the procedure definition.
  한글 번역: (참/거짓) Microsoft 어셈블러에서는 프로시저 정의에 NESTED 연산자를 사용하지 않으면 중첩 프로시저 호출이 허용되지 않는다.
    정답: False
    해설: 프로시저 안에서 다른 프로시저를 호출하는 중첩 호출은 일반적으로 가능하다. NESTED는 호출 자체를 허용하기 위한 필수 조건이 아니다.

8. (True/False): In protected mode, each procedure call uses a minimum of 4 bytes of stack space.
  한글 번역: (참/거짓) 보호 모드에서 각 프로시저 호출은 최소 4바이트의 스택 공간을 사용한다.
    정답: True
    해설: 32비트 보호 모드에서 CALL 명령어는 반환 주소를 스택에 저장한다. 반환 주소가 32비트이므로 4바이트가 필요하다.

9. (True/False): The ESI and EDI registers cannot be used when passing 32-bit parameters to procedures.
  한글 번역: (참/거짓) 프로시저에 32비트 매개변수를 전달할 때 ESI와 EDI 레지스터를 사용할 수 없다.
    정답: False 
    해설: ESI와 EDI도 범용 레지스터이므로 매개변수 전달에 사용할 수 있다. 
         다만 특정 호출 규약에서는 레지스터의 용도나 보존 규칙이 정해질 수 있다.

10. (True/False): The ArraySum procedure (Section 5.2.5) receives a pointer to any array of doublewords.
  한글 번역: (참/거짓) 5.2.5절의 ArraySum 프로시저는 임의의 더블워드 배열을 가리키는 포인터를 전달받는다.
    정답: True
    해설: 더블워드는 32비트(4바이트) 데이터다. ArraySum은 배열의 시작 주소를 전달받아 배열 요소들을 순회하며 합계를 계산한다. 
         단, 배열의 요소 개수 등 필요한 추가 정보도 함께 전달해야 한다.

11. (True/False): The USES operator lets you name all registers that are modified within a procedure.
  한글 번역: (참/거짓) USES 지시어를 사용하면 프로시저 내부에서 변경되는 모든 레지스터를 지정할 수 있다.
    정답: True
    해설: MASM의 USES 지시어는 프로시저에서 보존해야 할 레지스터를 지정한다. MASM은 해당 레지스터를 자동으로 저장하고 복원하는 코드를 생성한다. 
         단, 실제로 보존할 레지스터를 프로그래머가 지정해야 한다.

12. (True/False): The USES operator only generates PUSH instructions, so you must code POP instructions yourself.
  한글 번역: (참/거짓) USES 지시어는 PUSH 명령어만 생성하므로 POP 명령어는 직접 작성해야 한다.
    정답: False

14. Which statement(s) in the ArraySum procedure (Section 5.2.5) would have to be modified so it could accumulate an array of 16-bit words? Create such a version of ArraySum and test it
  한글 번역: 16비트 워드 배열의 합계를 계산하도록 ArraySum 프로시저를 수정하려면 어떤 문장을 변경해야 하는가? 수정된 ArraySum을 작성하고 테스트하시오.
    정답: 배열 요소를 읽는 명령어와 배열 포인터를 증가시키는 명령어를 수정해야 한다. 합계는 32비트로 유지한다.
    수정 사항:
        add eax, [esi] → add eax, [esi] (2바이트만 더함)
        add esi, 4 → add esi, 2 (워드는 2바이트씩 이동)

    < ArraySum: >
    ArraySumWords PROC
    ; ECX = 배열 요소 개수
    ; ESI = 배열 주소
    ; 반환값: EAX = 합계
      mov eax,0
      test ecx,ecx
      jz done
    L1:
      movzx edx, WORD PTR [esi]  ; 부호 없는 확장
      add eax,edx
      add esi,2                  ; 워드는 2바이트
      loop L1
    done:
      ret
    ArraySumWords ENDP

    < 테스트 코드: >
    .data
    myWords WORD 100h, 200h, 300h, 400h
    count = 4
    .code
    main PROC
      mov esi, OFFSET myWords
      mov ecx, count
      call ArraySumWords
      ; EAX = 0A00h (2560)
      INVOKE ExitProcess,0
    main ENDP

    pop eax

    POP EAX	       []          5를 꺼내 EAX에 저장    5

20. What values will be written to the array when the following code executes?
  한글 번역: 다음 코드가 실행될 때 배열에 어떤 값들이 저장되는가?

    .data
    array DWORD 4 DUP(0)
    .code
    main PROC
      mov eax,10
      mov esi,0
      call proc_1
      add esi,4
      add eax,10
      mov array[esi],eax
      INVOKE ExitProcess,0
    main ENDP

    proc_1 PROC
      call proc_2
      add esi,4
      add eax,10
      mov array[esi],eax
      ret
    proc_1 ENDP

    proc_2 PROC
      call proc_3
      add esi,4
      add eax,10
      mov array[esi],eax
      ret
    proc_2 ENDP

    proc_3 PROC
      mov array[esi],eax
      ret
    proc_3 ENDP

    정답: 배열에는 순서대로 10, 20, 30, 40이 저장된다.
    해설:
     DWORD는 4바이트이므로 ESI를 4씩 증가시키면 다음 배열 요소로 이동.

     [실행 순서]	 [실행 위치]	      [ESI]	      [EAX]     [저장 결과]
     1	          proc_3	          0	          10	        array[0] = 10
     2	          proc_2	          4	          20	        array[4] = 20
     3	          proc_1	          8	          30	        array[8] = 30
     4	          main	            12	         40	        array[12] = 40
