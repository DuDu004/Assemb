1. Integer Expression Calculation
Using the AddTwo program from Section 3.2 as a reference, write a program that calculates the
following expression, using registers: A = (A + B) − (C + D). Assign integer values to the EAX,
EBX, ECX, and EDX registers.

.386
.model flat,stdcall
.stack 4096
ExitProcess PROTO, dwExitCode:DWORD

.code
main PROC
    ; 초기 값 할당 (예의상 임의의 값 지정)
    mov eax, 10      ; A = 10
    mov ebx, 20      ; B = 20
    mov ecx, 5       ; C = 5
    mov edx, 2       ; D = 2

    ; 수식 계산: A = (A + B) - (C + D)
    add eax, ebx     ; EAX = A + B (10 + 20 = 30)
    add ecx, edx     ; ECX = C + D (5 + 2 = 7)
    sub eax, ecx     ; EAX = (A + B) - (C + D) (30 - 7 = 23)

    INVOKE ExitProcess, 0
main ENDP
END main
