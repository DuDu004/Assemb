x86 Assembly — Conditional Jumps 정리 노트
1. Conditional Jump란?

조건부 점프(Conditional Jump)는 특정 조건이 참일 때 지정한 레이블(Label)로 이동하는 명령어이다.

주로 CMP 명령어로 두 값을 비교한 뒤 사용한다.

mov eax, 5
cmp eax, 10
jl Smaller

; 점프하지 않았다면 실행되는 코드

Smaller:
; eax가 10보다 작을 때 실행되는 코드

CMP의 기본 원리
CMP destination, source

내부적으로 destination - source를 수행한 것처럼 플래그를 설정한다.
실제 피연산자의 값은 변경하지 않는다.
조건부 점프는 CMP가 설정한 플래그를 확인한다.

예를 들어 다음과 같다.

cmp eax, ebx
je EqualLabel


EAX와 EBX가 같으면 EqualLabel로 점프한다.

핵심: CMP는 비교 결과에 따라 플래그를 설정하고, 조건부 점프는 그 플래그를 이용해 분기한다.
2. 알아야 할 주요 플래그
플래그	이름	의미
ZF	Zero Flag	연산 결과가 0이면 1
CF	Carry Flag	부호 없는 뺄셈에서 빌림이 발생하면 1
SF	Sign Flag	결과의 최상위 비트가 1이면 1
OF	Overflow Flag	부호 있는 연산에서 오버플로가 발생하면 1
PF	Parity Flag	결과의 하위 8비트에서 1의 개수가 짝수이면 1
플래그별 간단한 예시
cmp eax, ebx

비교 상황	ZF	CF	설명
EAX = EBX	1	0	두 값이 같음
EAX < EBX (unsigned)	0	1	빌림 발생
EAX > EBX (unsigned)	0	0	빌림 없음

주의: SF와 OF는 부호 있는 비교에서 함께 해석해야 한다. SF만으로 대소 관계를 항상 판단할 수 있는 것은 아니다.

3. 특정 플래그 값에 따른 점프

이 명령어들은 특정 플래그가 0인지 1인지를 직접 검사한다.

명령어	의미	점프 조건
JZ	0이면 점프	ZF = 1
JNZ	0이 아니면 점프	ZF = 0
JC	캐리 발생 시 점프	CF = 1
JNC	캐리가 없으면 점프	CF = 0
JO	오버플로 발생 시 점프	OF = 1
JNO	오버플로가 없으면 점프	OF = 0
JS	부호 플래그가 1이면 점프	SF = 1
JNS	부호 플래그가 0이면 점프	SF = 0
JP	패리티가 짝수이면 점프	PF = 1
JNP	패리티가 홀수이면 점프	PF = 0
예제: JZ와 JNZ
mov eax, 10
cmp eax, 10
jz EqualLabel


10 - 10 = 0이므로 ZF = 1이다. 따라서 EqualLabel로 점프한다.

mov eax, 10
cmp eax, 5
jnz NotEqualLabel


10 - 5 = 5이므로 ZF = 0이다. 따라서 NotEqualLabel로 점프한다.

기억할 점
JZ와 JNZ는 결과가 0인지 아닌지를 검사한다.
JC와 JNC는 캐리 플래그를 검사한다.
JO와 JNO는 오버플로 플래그를 검사한다.
JS와 JNS는 부호 플래그를 검사한다.
JP와 JNP는 패리티 플래그를 검사한다.
4. 동등성(Equality)에 따른 점프

두 값이 같은지 또는 다른지를 검사하거나, 특정 카운터 레지스터가 0인지 검사한다.

명령어	의미	조건
JE	같으면 점프	ZF = 1
JNE	다르면 점프	ZF = 0
JCXZ	CX가 0이면 점프	CX = 0
JECXZ	ECX가 0이면 점프	ECX = 0
JRCXZ	RCX가 0이면 점프	RCX = 0 (64비트 모드)
JE와 JNE

JE와 JZ는 같은 조건을 검사하며, JNE와 JNZ도 같은 조건을 검사한다.

cmp eax, ebx
je EqualLabel
jne NotEqualLabel

EAX == EBX이면 EqualLabel로 점프한다.
EAX != EBX이면 NotEqualLabel로 점프한다.
JCXZ 계열

이 명령어들은 이전 CMP의 결과 플래그가 아니라 지정된 레지스터 자체가 0인지 검사한다.

mov cx, 0
jcxz ZeroCount


CX가 0이므로 ZeroCount로 점프한다.

주의: JCXZ, JECXZ, JRCXZ는 ZF를 검사하는 명령어가 아니다.
5. 부호 없는 비교 (Unsigned Comparison)

부호 없는 정수는 모든 비트를 크기를 나타내는 데 사용한다.

예를 들어 8비트에서 11111111은 부호 없는 수로 255이다.

부호 없는 비교에서는 주로 CF와 ZF를 이용한다.

명령어	의미	조건식	플래그 조건
JA	초과	A > B	CF = 0 AND ZF = 0
JNBE	이하가 아니면 점프	A > B	CF = 0 AND ZF = 0
JAE	이상	A >= B	CF = 0
JNB	미만이 아니면 점프	A >= B	CF = 0
JB	미만	A < B	CF = 1
JNAE	이상이 아니면 점프	A < B	CF = 1
JBE	이하	A <= B	CF = 1 OR ZF = 1
JNA	초과가 아니면 점프	A <= B	CF = 1 OR ZF = 1

여기서 A와 B는 비교하는 두 피연산자를 의미한다. CMP에서는 A가 목적지 피연산자이고 B가 소스 피연산자이다.

암기법
A = Above (초과)
AE = Above or Equal (이상)
B = Below (미만)
BE = Below or Equal (이하)
예제
mov eax, 10
mov ebx, 5
cmp eax, ebx
ja AboveLabel


부호 없는 비교에서 10 > 5이므로 CF = 0, ZF = 0이다. 따라서 JA는 점프한다.

mov eax, 5
mov ebx, 10
cmp eax, ebx
jb BelowLabel


부호 없는 비교에서 5 < 10이므로 CF = 1이다. 따라서 JB는 점프한다.

별칭 관계

다음 명령어들은 같은 조건을 검사한다.

JA = JNBE
JAE = JNB
JB = JNAE
JBE = JNA
6. 부호 있는 비교 (Signed Comparison)

부호 있는 정수는 음수와 양수를 모두 표현한다.

부호 있는 비교에서는 SF, OF, ZF를 이용한다.

명령어	의미	조건식	플래그 조건
JG	초과	A > B	ZF = 0 AND SF = OF
JNLE	이하가 아니면 점프	A > B	ZF = 0 AND SF = OF
JGE	이상	A >= B	SF = OF
JNL	미만이 아니면 점프	A >= B	SF = OF
JL	미만	A < B	SF != OF
JNGE	이상이 아니면 점프	A < B	SF != OF
JLE	이하	A <= B	ZF = 1 OR SF != OF
JNG	초과가 아니면 점프	A <= B	ZF = 1 OR SF != OF
암기법
G = Greater (초과)
GE = Greater or Equal (이상)
L = Less (미만)
LE = Less or Equal (이하)
왜 SF와 OF를 함께 사용할까?

부호 있는 뺄셈에서 오버플로가 발생하면 결과의 부호 비트만으로 실제 대소 관계를 판단할 수 없다.

예를 들어 8비트 부호 있는 정수에서 다음 연산을 생각해 보자.

127 - (-1)


수학적으로 결과는 128이지만, 8비트 부호 있는 정수의 최댓값은 127이므로 오버플로가 발생한다.

따라서 부호 있는 비교에서는 SF와 OF의 관계를 함께 확인한다.

SF = OF이면 부호 있는 비교에서 목적지 값이 소스 값 이상일 수 있다.
SF != OF이면 목적지 값이 소스 값보다 작다.
같음 여부는 ZF를 추가로 확인한다.
예제
mov eax, -5
mov ebx, 3
cmp eax, ebx
jl LessLabel


부호 있는 비교에서 -5 < 3이므로 JL은 점프한다.

별칭 관계
JG = JNLE
JGE = JNL
JL = JNGE
JLE = JNG
7. 가장 중요한 차이: Signed vs. Unsigned

동일한 비트 패턴도 부호 있는 정수인지 부호 없는 정수인지에 따라 의미가 달라진다.

8비트 값 11111111을 예로 들어 보자.

해석 방법	값
Unsigned	255
Signed (2의 보수)	-1

따라서 비교 명령어를 사용할 때는 값이 부호 있는 정수인지 반드시 확인해야 한다.

점프 명령어 비교표
비교 관계	Unsigned	Signed
초과 (>)	JA	JG
이상 (>=)	JAE	JGE
미만 (<)	JB	JL
이하 (<=)	JBE	JLE
같음 (==)	JE	JE
다름 (!=)	JNE	JNE

시험 핵심: 크기 비교는 Signed/Unsigned에 따라 명령어가 달라지지만, 같음과 다름을 검사하는 JE와 JNE는 두 해석 방식에서 동일하게 사용할 수 있다.

8. C언어 조건문과 비교하기

C언어의 조건문과 어셈블리 점프를 연결하면 이해하기 쉽다.

예제 1: 같으면 점프
if (a == b) {
    // Equal
}

cmp eax, ebx
je Equal

예제 2: 부호 있는 정수에서 작으면 점프
if (a < b) {
    // Less
}

cmp eax, ebx
jl Less

예제 3: 부호 없는 정수에서 크면 점프
if (a > b) {
    // Above
}

cmp eax, ebx
ja Above

9. 최종 암기 노트
특정 플래그 검사
JZ / JNZ: ZF 검사
JC / JNC: CF 검사
JO / JNO: OF 검사
JS / JNS: SF 검사
JP / JNP: PF 검사
동등성 검사
JE: 같음
JNE: 다름
JCXZ: CX = 0
JECXZ: ECX = 0
JRCXZ: RCX = 0
부호 없는 비교
JA: 초과
JAE: 이상
JB: 미만
JBE: 이하
부호 있는 비교
JG: 초과
JGE: 이상
JL: 미만
JLE: 이하
최종 암기 공식
Unsigned: Above / Below 계열
Signed: Greater / Less 계열

크기 비교를 하기 전에는 항상 피연산자가 부호 있는 값인지, 부호 없는 값인지 확인하자.
