9. In the following instruction sequence, show the values of the Carry, Zero, and Sign flags where indicated:
    mov al,00001111b
    test al,00000010b       ; a. CF= ZF= SF=
    mov al,00000110b
    cmp al,00000101b        ; b. CF= ZF= SF=
    mov al,00000101b
    cmp al,00000111b        ; c. CF= ZF= SF=

    정답: 문제       CF        ZF        SF
            a:        0        0        0        -> 결과 02h, 최상위 비트가 0
            b:        0        0        0        -> 06h - 05h = 01h
            c:        1        0        1        -> 05h - 07h = FEh (8비트 결과)
    [TEST] : AND 연산 결과로 플래그를 설정하지만, 결과를 AL에 저장하지 않는다.
    [CMP]  : 뺄셈 결과로 플래그를 설정하지만, 결과를 저장하지 않는다.

10. Which conditional jump instruction executes a branch based on the contents of ECX?

    정답: JECXZ
        => 만약 ECX = 0 이라면 JUMP한다.

11. How are JA and JNBE affected by the Zero and Carry flags?

    정답: JA와 JNBE는 동일한 조건으로 분기한다.
        - 분기 조건: CF = 0 그리고 ZF = 0
        - 즉,  unsigned 비교에서 왼쪽 값이 오른쪽 값보다 클 때 분기한다.

12. What will be the final value in EDX after this code executes?
    mov edx,1
    mov eax,7FFFh
    cmp eax,8000h
    jl L1
    mov edx, 0
  L1:

    정답: EDX = 1
        => JL은 signed 비교이므로 7FFFh < 8000h가 참이라 L1로 분기

13. What will be the final value in EDX after this code executes?
    mov edx,1
    mov eax,7FFFh
    cmp eax,8000h
    jb L1
    mov edx,0
  L1:

    정답: EDX = 0
        => JB는 unsigned 비교에서 왼쪽 값이 더 작을 때 분기

14. What will be the final value in EDX after this code executes?
    mov edx,1
    mov eax,7FFFh
    cmp eax,0FFFF8000h
    jl L2
    mov edx,0
  L2:

    정답: EDX = 0
        => 7FFFh < -32768은 거짓이므로 mov edx,0이 실행

15. (True/False): The following code will jump to the label named Target.
    mov eax, -30
    cmp eax, -50
    jg Target

    정답: True
        => -30 > -50 은 참이다.
        => JG는 signed 비교에서 왼쪽 값이 더 클 때 분기.

16. (True/False): The following code will jump to the label named Target.
    mov eax, -42
    cmp eax, 26
    ja Target

    정답: True
